# BLOGDEN - Full Stack Blog Website

A Full Stack Blog Website developed as part of a **14-Day Full Stack Development Internship** at **Codomax Digital Solutions**.

BLOGDEN is built using **React.js** for the frontend and **Node.js + Express.js** for the backend. The project is being developed step by step, covering frontend development, backend APIs, CRUD operations, and full-stack integration.

---

# 🚀 Features

## Frontend

- Responsive Home Page
- Add Blog Page
- Navigation Bar
- Footer
- Bootstrap 5 UI
- Form Validation
- Responsive Design

## Backend

- Express.js Server
- GET API
- POST API
- Add Blog API
- View Blogs API
- JSON Request Handling
- JavaScript Array Storage
- Input Validation

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/BLOGDEN.git
```

Navigate to the project folder.

```bash
cd BLOGDEN
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend runs at:

```text
http://localhost:5000
```

---

## Frontend Setup

```bash
cd blog
npm install
npm run dev
```

Frontend runs at:

```text
http://localhost:5173
```
